# Personal Portfolio — HTML5 + CSS3

## Files
- `index.html`: semantic structure and English-language content.
- `styles.css`: responsive styling and CSS-only abstract illustrations.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or serve the folder with any static web server.
3. Replace `your-email@example.com` with your professional email.
4. Add links to public repositories, demos, and deployed projects when available.

No JavaScript or frontend framework is required. Google Fonts needs an internet connection; remove the `@import` at the top of `styles.css` for an offline version (fallback fonts will be used).
